# מבחן אבחוני — רמה A1.1

## הוראות

שלום וברוכים הבאים למבחן האבחוני לרמה A1.1 בטורקית!

**מטרת המבחן:** לבדוק את רמת הידע שלך בטורקית ברמת מתחילים (A1.1).

**הנחיות כלליות:**
- המבחן כולל 30 פריטים המחולקים לארבעה חלקים.
- זמן מומלץ: 45 דקות.
- ענה/ענו על כל השאלות. אין קנס על תשובה שגויה.
- בשאלות תרגום — תרגם/י לכיוון המבוקש (טורקית ← עברית או עברית ← טורקית).
- בשאלות השלמה (cloze) — מלא/י את החסר בטורקית.
- בשאלות רב-ברירה — סמן/י תשובה אחת בלבד.

# מפתח תשובות

### חלק א: דקדוק

**1.**
> Nasıl**sınız** / Nasıl**sın**?
> İyiyim, **teşekkür** ederim.

📝 **הסבר:** הצורה הנימוסית היא "Nasılsınız?" (=?מה שלומכם). הצורה הבלתי-פורמלית: "Nasılsın?" (=?מה שלומך). "Teşekkür ederim" = "תודה (רבה)". שים/י לב: "teşekkür" (שם עצם) + "ederim" (אני עושה) = ביטוי קבוע.

**2.** ג) Hoşça kal

📝 **הסבר:** "Hoşça kal" = "להתראות" (נאמר על ידי ההולך לנשאר, מילולית: "הישאר בנעימים"). הנשאר עונה "Güle güle" (= "לך בחיוך"). "Merhaba" = "שלום". "Günaydın" = "בוקר טוב". "Teşekkürler" = "תודות".

**3.**
> Günaydın, nasılsın? / Günaydın, nasılsınız?

📝 **הסבר:** "Günaydın" = "בוקר טוב" (gün = יום, aydın = מואר). שים/י לב שבטורקית הברכה היא מילה אחת.

**4.**
> Ben şimdi kitap **okuyorum**.

📝 **הסבר:** ההווה הממשיך: גזע + -(I)yor + סיומת גוף. okumak → גזע: oku- → oku + yor + um = okuyorum. כשהגזע נגמר בתנועה (oku-), הוא מתחבר ישירות ל-yor.

**5.**
> Onlar parkta **koşuyorlar**.

📝 **הסبر:** koşmak → koş + uyor + lar = koşuyorlar. שים/י לב: התנועה u נבחרת לפי הרמוניית התנועות (koş → o/u). הסיומת -lar היא רבים גוף שלישי (אופציונלית בטורקית מדוברת).

**6.** א) Sen geliyorsun.

📝 **הסبר:** ההטיה הנכונה של gelmek בהווה ממשיך לגוף שני יחיד: gel + iyor + sun = geliyorsun. הסיומות האישיות ב-şimdiki zaman: -um, -sun, -(yok), -uz, -sunuz, -lar.

**7.**
> Dün akşam biz sinemaya **gittik**.

📝 **הסבר:** gitmek בעבר מוחלט (-DI): git → gitt + i + k = gittik. שים/י לב: שורשים שמסתיימים ב-t מכפילים אותו לפני סיומת שמתחילה בתנועה. הסיומת -k היא לגוף ראשון רבים.

**8.**
> "עלי לא בא אתמול לבית הספר."

📝 **הסבר:** gelmedi = לא בא (gel + me + di, כאשר -me- היא סיומת השלילה). okul = בית ספר. okula = לבית הספר (כיוון, יחסת Dative). dün = אתמול.

**9.** א) ettiniz

📝 **הסبر:** "Siz" = אתם/אתן (או צורת כבוד). kahvaltı etmek = לאכול ארוחת בוקר (פועל מורכב). עבר מוחלט עם siz: ett + iniz = ettiniz. ב) ettiler = הם/הן. ג) ettin = את/ה. ד) ettim = אני.

**10.**
> Masada iki bardak **var**. Ama tabak **yok**.

📝 **הסבר:** var = יש, yok = אין. "Masada" = על השולחן (masa + da, יחסת Locative). "bardak" = כוס, "tabak" = צלחת. המבנה: מקום + שם עצם + var/yok.

**11.**
> Buzdolabında süt yok.

📝 **הסבר:** buzdolabı = מקרר (buz = קרח + dolap = ארון + ı = שייכות). buzdolabında = במקרר (Locative). süt = חלב. yok = אין.

**12.**
> Annem market**e** gidiyor.

📝 **הסبר:** השאלה "לאן?" מצביעה על יחסת Dative (-A): -e/-a. "market" מסתיים בעיצור, ומכיוון שהתנועה האחרונה היא e (תנועה קדמית), הסיומת היא -e. gidiyor = הולכת.

**13.** ב) İstanbul'dan geldim.

📝 **הסבר:** Ablative (-DAn) מציינת מקור/ממנו. "İstanbul'dan geldim" = "באתי מאיסטנבול". א) -a = Dative (אליו). ג) -da = Locative (בו). ד) -un = Genitive (של) — ולא מתאים כאן כלל.

**14.**
> Kitab**ın** kapağ**ını** gördüm.

📝 **הסבר:** "kitabın" = של הספר (Genitive: kitap → kitab + ın). "kapağını" = את הכריכה שלו (kapak → kapağ + ı [שייכות] + n + ı [Accusative]). שרשרת שייכות: Genitive + שם עצם + סיומת שייכות. gördüm = ראיתי.

**15.**
> Arkadaşımızın evi

📝 **הסبר:** שרשרת שייכות (İzafet): arkadaş + ımız + ın (Genitive של "הידיד שלנו") + ev + i (שייכות גוף שלישי). "arkadaşımızın" = של הידיד שלנו. "evi" = ביתו.

### חלק ב: אוצר מילים

**16.**
> א-2 (su = מים), ב-1 (ekmek = לחם), ג-4 (okul = בית ספר), ד-3 (iş = עבודה)

**17.**
> Saat **sekiz**. Kahvaltı zamanı!

📝 **הסבר:** sekiz = 8. "Kahvaltı zamanı" = זמן ארוחת הבוקר. המספרים 1-10: bir, iki, üç, dört, beş, altı, yedi, sekiz, dokuz, on.

**18.** ג) mavi

📝 **הסבר:** mavi = כחול. kırmızı = אדום. yeşil = ירוק. sarı = צהוב.

**19.**
> "היום מזג האוויר חם מאוד."

📝 **הסبר:** bugün = היום (bu + gün = היום הזה). hava = מזג אוויר/אוויר. çok = מאוד. sıcak = חם. "Çok sıcak" = חם מאוד.

**20.**
> Evimizde **üç** kedi ve **iki** köpek var.

📝 **הסבר:** üç = 3, iki = 2. "Evimizde" = בבית שלנו (ev + imiz + de). kedi = חתול, köpek = כלב.

**21.** ב) יפה/טוב

📝 **הסבר:** güzel = יפה, נחמד, טוב. büyük = גדול, küçük = קטן, eski = ישן.

**22.**
> Babam yeni bir **araba** aldı.

📝 **הסבר:** araba = מכונית. "yeni" = חדש. "aldı" = קנה (almak = לקנת/לקחת). ההקשר — "נוסע בה לעבודה" — מצביע על מכונית.

**23.**
> Türk müziğini seviyorum. / Ben Türk müziği seviyorum.

📝 **הסبר:** sevmek = לאהוב. "Türk müziği" = מוזיקה טורקית (צירוף שייכות). עם Accusative מוגדר: müziğini. seviyorum = אני אוהב/ת.

### חלק ג: קריאה

**24.** ג) מורה

📝 **הסבר:** "Annem öğretmen" = "אמי מורה". öğretmen = מורה. doktor = רופא (זה אביה). mühendis = מהנדס (זה אחיה).

**25.**
> "אנחנו בסופי שבוע תמיד אוכלים ארוחת בוקר ביחד."

📝 **הסבר:** hafta sonları = בסופי שבוע. hep birlikte = תמיד ביחד. kahvaltı yapıyoruz = אנחנו עושים/אוכלים ארוחת בוקר.

**26.**
> Elif'in **iki** kardeşi var.

📝 **הסبר:** לפי הטקסט: "İki kardeşim var: bir ağabeyim ve bir kız kardeşim." — יש לאליף שני אחים (אח ואחות).

**27.** תשובה לדוגמה:
> - המשפחה אוכלת ארוחת בוקר ביחד.
> - האם מכינה בורקס.
> - אליף שותה תה, האחים שותים חלב, והאב קורא עיתון.

### חלק ד: כתיבה

**28.** תשובה לדוגמה:
> Benim adım David. Ben yirmi beş yaşındayım. Tel Aviv'de yaşıyorum.

📝 **קריטריונים:** שימוש נכון ב-benim adım, yaşındayım, ו-Locative למקום מגורים (-DA).

**29.** תשובה לדוגמה:
> — Merhaba! Benim adım Ayşe. Senin adın ne?
> — Merhaba, Ayşe! Ben Yusuf. Nasılsın?
> — İyiyim, teşekkür ederim. Sen nasılsın?
> — Ben de iyiyim, sağ ol!

📝 **קריטריונים:** פתיחה מנומסת, הצגה עצמית, שאלה הדדית, סיום.

**30.** תשובה לדוגמה:
> Dün sabah kahvaltı yaptım. Sonra okula gittim. Akşam arkadaşlarımla buluştum.

📝 **קריטריונים:** שימוש נכון בעבר מוחלט (-DI), ציוני זמן (dün, sonra, akşam), הטיה נכונה.

### רשימת "אני יכול/ה" — A1.1

- [ ] אני יכול/ה להציג את עצמי ולשאול שאלות בסיסיות (שם, גיל, מקום מגורים).
- [ ] אני יכול/ה להשתמש בהווה ממשיך (-Iyor) כדי לתאר פעולות כרגע.
- [ ] אני יכול/ה להשתמש בעבר מוחלט (-DI) כדי לספר על אירועים שקרו.
- [ ] אני יכול/ה להשתמש ב-var/yok כדי לתאר קיום/העדר.
- [ ] אני יכול/ה לזהות ולהשתמש בשש היחסות (Nominative, Accusative, Dative, Locative, Ablative, Genitive).
- [ ] אני יכול/ה ליצור צירופי שייכות פשוטים (evi, kitabım, annemin).
- [ ] אני יכול/ה להחיל הרמוניית תנועות בסיומות בסיסיות.
- [ ] אני יכול/ה לספור ולהשתמש במספרים עד 100.
- [ ] אני יכול/ה להבין טקסט קצר ופשוט על נושא יומיומי (משפחה, שגרה).
- [ ] אני יכול/ה לכתוב משפטים פשוטים על עצמי ועל חיי היום-יום.

# מבחן אבחוני — רמה B1

## הוראות

שלום וברוכים הבאים למבחן האבחוני לרמה B1 בטורקית!

**מטרת המבחן:** לבדוק את הידע שלך ברמת B1 — כולל כל החומר מרמות קודמות בתוספת בינוניות (participles), שמות פועל (verbal nouns), פעלים מורכבים ורגיסטר רשמי.

**הנחיות כלליות:**
- המבחן כולל 40 פריטים המחולקים לארבעה חלקים.

# מפתח תשובות

### חלק א: דקדוק

**1.**
> Keşke daha çok çalış**saydım**, sınavı geç**erdim**.

📝 **הסבר:** תנאי בלתי מתקיים בעבר: -sAydI... -(A/I)rdI. "אם הייתי לומד/ת יותר, הייתי עובר/ת את המבחן." çalışsaydım = עבדתי (היפותטי); geçerdim = הייתי עובר.

**2.**
> Yemek şef tarafından hazırlandı.

📝 **הסبר:** סביל: hazırlamak → hazırla + n + dı = hazırlandı. "tarafından" = על ידי. בסביל, שם הפועל מקבל -(I)n כשהוא מסתיים בתנועה.

**3.**
> Müdür mektubu sekreterine **yazdırdı**.

📝 **הסבר:** גרימה של yazmak: yaz + dır + dı = yazdırdı. "המנהל גרם למזכירתו לכתוב את המכתב."

**4.** א) Ben gelseydim, seni görürdüm.

📝 **הסبر:** תנאי בלתי מתקיים: -sAydI (פסוקית תנאי) + -(A/I)rdI (פסוקית תוצאה). "אם הייתי בא, הייתי רואה אותך."

**5.**
> O zamanlar her akşam birlikte yemek **yerdik**.

📝 **הסבר:** אאוריסט + עבר (הרגל בעבר): yemek → ye + r + di + k = yerdik. "באותם ימים היינו אוכלים ביחד כל ערב."

**6.**
> Masada **oturan** adam babam.

📝 **הסבר:** בינונית -(y)An: oturmak → otur + an = oturan. "האיש ה**יושב** ליד השולחן." -(y)An מתפקדת כשם תואר ומגדירה את הנושא שעושה את הפעולה.

**7.**
> Dün **aldığım** kitabı çok beğendim.

📝 **הסبר:** בינונית -DIK + סיומת שייכות: almak → al + dığ + ım = aldığım. "הספר ש**קניתי**." שים/י לב: -DIK דורשת סיומת שייכות כי היא מציינת שהנושא (אני) עשה את הפעולה על המושא (הספר).

**8.** ב) -(y)An = הנושא עושה את הפעולה; -DIK = הנושא הוא המושא של הפעולה

📝 **הסבר:** -(y)An (subject participle): "okuyan adam" = האיש שקורא. -DIK (object participle): "okuduğum kitap" = הספר שקראתי. ב-(-y)An הנושא מבצע; ב-(-DIK) הנושא חיצוני והמילה המתוארת היא המושא.

**9.**
> Yarın **izleyeceğimiz** film çok güzelmiş.

📝 **הסבר:** בינונית -(y)AcAK + שייכות: izlemek → izle + yecek + imiz = izleyeceğimiz. "הסרט שנצפה (בו) מחר." שים/י לב: -(y)AcAK כבינונית מציינת עתיד.

**10.**
> "האדם החכם ביותר שאני מכיר/ה הוא/היא אמי."

📝 **הסבר:** "tanıdığım" = שאני מכיר/ה (בינונית -DIK + שייכות גוף ראשון). "en zeki" = הכי חכם. "insan" = אדם.

**11.**
> Bu, benim en çok **sevdiğim** şarkı.

📝 **הסבר:** בינונית -DIK + שייכות: sevmek → sev + diğ + im = sevdiğim. "השיר שאני הכי אוהב/ת." -DIK כי "אני" (הנושא) אוהב את "השיר" (המושא).

**12.**
> Türkçe **öğrenmek** istiyorum.

📝 **הסבר:** -mAK = שם פועל מופשט, משמש אחרי פעלים כמו istemek (לרצות), sevmek (לאהוב). "אני רוצה ללמוד טורקית."

**13.**
> **Yüzme** bilmiyorum.

📝 **הסבר:** -mA = שם פועל קונקרטי. "yüzme bilmek" = לדעת לשחות. -mA נפוץ עם bilmek (לדעת), başlamak (להתחיל).

**14.**
> Onun İstanbul'a **gittiğini** biliyorum.

📝 **הסבר:** -DIK + סיומת שייכות + Accusative: gitmek → git + tiğ + i (שייכות גוף שלישי) + ni (Accusative) = gittiğini. "אני יודע/ת שהוא הלך לאיסטנבול." bilmek דורש את פסוקית ה-(-DIK) ב-Accusative.

**15.** ג) Seni gördüğüme

📝 **הסבר:** "Seni gördüğüme çok mutlu oldum" = שמחתי מאוד שראיתי אותך. -DIK + שייכות + Dative (-A). "gördüğüme" = שראיתי (בזה ש...). mutlu olmak + Dative.

**16.**
> Onun gelmeyeceğinden korkuyorum. / Onun gelmemesinden korkuyorum.

📝 **הסבר:** korkmak + -DAn. שתי אפשרויות: א) -(y)AcAK + Ablative: gelmeyeceğinden. ב) -mA + שלילה + Ablative: gelmemesinden. "אני מפחד/ת שהוא לא יבוא."

**17.**
> Onun **yürüyüşü** çok komik.

📝 **הסבר:** -(y)Iş = שם פועל שמתאר את אופן הפעולה: yürümek → yürü + yüş + ü (שייכות) = yürüyüşü. "ההליכה שלו מאוד מצחיקה."

**18.**
> א-2 (devam etmek = להמשיך), ב-3 (karar vermek = להחליט), ג-1 (başlamak = להתחיל), ד-4 (tercih etmek = להעדיף)

**19.**
> Doktor olma**ya** **karar verdim**.

📝 **הסبר:** "karar vermek" = להחליט. המבנה: -mA + Dative (-yA) + karar vermek. "החלטתי להיות רופא/ה."

**20.**
> Sigara içmeyi bırakmaya çalışıyorum. / Sigarayı bırakmaya çalışıyorum.

📝 **הסبר:** "bırakmak" = להפסיק. "çalışmak" = לנסות. המבנה: -mA + Dative + çalışmak. "אני מנסה להפסיק לעשן."

**21.**
> Türkiye'ye taşındıktan sonra, Türkçe **öğrenmeye başladım**.

📝 **הסבר:** "başlamak" = להתחיל. המבנה: -mA + Dative + başlamak. "taşındıktan sonra" = אחרי שעברתי (Ablative של -DIK + sonra).

**22.**
> א) "Yarın gelemeyeceğimi bildirmek isterim." / "Yarın katılma imkânım olmayacaktır."

📝 **הסבר:** ברגיסטר רשמי נמנעים מ-"ben" ומשתמשים במבנים עקיפים ומנומסים יותר.

> ב) "Bu işin ne zaman tamamlanacağını öğrenebilir miyim?" / "Söz konusu işin bitiş tarihini sormak isterim."

📝 **הסבר:** "bitecek" (יומיומי) → "tamamlanacak" (רשמי). שאלה ישירה → שאלה עקיפה מנומסת.

### חלק ב: אוצר מילים

**23.**
> א-2 (görüşme = ראיון/פגישה), ב-3 (başvuru = בקשה/מועמדות), ג-1 (fırsat = הזדמנות), ד-4 (deneyim = ניסיון/חוויה)

**24.** ב) להבטיח

📝 **הסבר:** "söz vermek" (מילולית: לתת מילה) = להבטיח. "söylemek" = להגיד. "konuşmak" = לדבר.

**25.**
> Bu kitap beni çok **etkiledi**.

📝 **הסבר:** "etkilemek" = להשפיע. "değerlendirmek" = להעריך. "geliştirmek" = לפתח.

**26.**
> Bu pozisyona başvurmakla ilgileniyorum. / Bu pozisyon için başvuruda bulunmak istiyorum.

📝 **הסבר:** "başvurmak" = להגיש מועמדות. "ilgilenmek" = להתעניין. "pozisyon" = משרה.

**27.** ב) לעלות על הדעת / להיזכר

📝 **הסבר:** "aklıma gelmek" (מילולית: לבוא לשכלי) = לעלות על הדעת, להיזכר. "Bir fikir aklıma geldi" = עלה לי רעיון.

**28.**
> Toplantıda herkes kendi **görüşünü** söyledi.

📝 **הסבר:** "görüş" = דעה/תפיסה. "görev" = משימה. "giriş" = כניסה. "görüşünü" = את דעתו (שייכות + Accusative).

**29.**
> "עלינו להעריך את תוצאות הפרויקט הזה."

📝 **הסبר:** "değerlendirmemiz gerekiyor" = עלינו להעריך (-mA + שייכות + gerekiyor). "sonuçlar" = תוצאות. "proje" = פרויקט.

**30.**
> İş görüşmesinde iyi bir izlenim **bırakmak** önemlidir.

### חלק ג: קריאה

**31.** ב) מכתב מועמדות לעבודה

📝 **הסבר:** "başvuruda bulunmak istiyorum" = אני רוצה להגיש מועמדות. "pozisyon için" = עבור המשרה. כל המבנה הוא מכתב מועמדות קלאסי.

**32.** תשובה לדוגמה:
> Elif, İstanbul Üniversitesi İşletme Bölümü'nden mezun oldu. Üç yıl bir reklam ajansında çalıştı, yani üç yıllık iş deneyimi var.

📝 **הסבר:** "İşletme Bölümü" = מחלקת מנהל עסקים. "üç yıl" = שלוש שנים. "deneyim" = ניסיון.

**33.** תשובה לדוגמה:
> 1. נוטה לעבודת צוות (ekip çalışmasına yatkın)
> 2. יצירתית (yaratıcı)
> 3. מכוונת תוצאות (sonuç odaklı)

**34.** ב) בינונית -DIK + סיומת שייכות

📝 **הסבר:** "yönettiğim" = שניהלתי. yönetmek → yönet + tiğ + im = yönettiğim. בינונית -DIK + שייכות גוף ראשון.

**35.**
> "אני מבקש/ת בכבוד רב שבקשתי תיבדק." / "מבקש/ת בכבוד שתשקלו את מועמדותי."

📝 **הסבר:** "başvurumun" = של מועמדותי. "değerlendirilmesini" = שתיבדק (סביל של değerlendirmek + -mA + שייכות + Accusative). "saygılarımla rica ederim" = מבקש בכבוד רב.

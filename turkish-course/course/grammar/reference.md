### א.2 הגיית צלילים בעייתיים

**ı (undotted i)**: הצליל הכי בעייתי לדוברי עברית. פתחו את הפה כאילו אתם אומרים "אַ" אבל הרימו את הלשון לאחור. מנסים להגיד "i" עם הלשון מאחור.

**ö**: אמרו "e" ועגלו את השפתיים כאילו אתם אומרים "o".

**ü**: אמרו "i" ועגלו את השפתיים כאילו אתם אומרים "u".

**ğ (yumuşak ge)**: לא צליל עצמאי! מאריך את התנועה שלפניו. dağ = [daː], değil = [deːil].

**r**: tap /ɾ/, לא ר גרוני. קצת כמו ד מהיר מאוד.

### א.3 הטעמה (Stress)
- **ברירת מחדל**: הטעמה על ההברה האחרונה: kitáp, geliyórum
- **חריגים**: שמות מקום (Ánkara, İstánbul), תארי פועל (yálnız), שלילה (gélmedi), שאלה (géldi mi?)
- **סיומות שלא מושכות הטעמה**: -mE (שלילה), -mI (שאלה), -(y)E (אופטטיב)

## חלק ד: תחביר

### ד.1 סדר מילים בסיסי — SOV
```
Subject + Object + Verb
Ali        elmayı    yiyor.
עלי       את-התפוח  אוכל.
```

### ד.2 מיקום מוקד (Focus Position)
מה שחשוב/חדש בא **מיד לפני הפועל**:
```
Ali DÜN geldi.          עלי אתמול בא. (מוקד = אתמול)
DÜN Ali geldi.          אתמול עלי בא. (neutral)
Ali geldi DÜN.          less natural
```

### ד.3 שאלות
- כן/לא: חלקיקית mI אחרי המילה המוטלת בספק
  ```
  Ali geldi mi?          האם עלי בא?
  Ali mi geldi?          האם עלי (הוא זה שבא)?
  ```
- שאלות פתוחות: מילת שאלה במיקום מוקד (לפני הפועל)
  ```
  Kim geldi?             מי בא?
  Ne yapıyorsun?         מה אתה עושה?
  Nereye gidiyorsun?     לאן אתה הולך?
  ```

### ד.4 שלילה
- פעלים: -mE/-mA (gel-me-dim = לא באתי)
- שמות: değil (öğrenci değilim = אני לא תלמיד)
- קיום: yok (Para yok = אין כסף)

### ד.5 var/yok — "יש"/"אין"
```
Sütümüz var.     יש לנו חלב.     (literally: חלב-שלנו קיים)
Param yok.       אין לי כסף.     (literally: כסף-שלי אין)
```
מקבילה מצוינת לעברית: "יש לי X" = "X-ım var"

### ד.6 סמיכות (Possessive Compound / İzafet)

**סוג 1: Definite İzafet** (GEN + POSS)
```
Ali'nin evi          הבית של עלי
  Ali-GEN house-3POSS

öğretmenin kitabı    הספר של המורה
```

**סוג 2: Indefinite İzafet** (∅ + POSS)
```
okul kapısı          שער בית ספר
  school door-3POSS

çay bardağı          כוס תה
  tea glass-3POSS
```

**סוג 3: Qualifying Compound** (∅ + ∅)
```
demir kapı           שער ברזל (שער מברזל)
  iron door

taş duvar            קיר אבן
  stone wall
```

## חלק ו: צורות מתקדמות (B2–C1)

### ו.1 סביל (Passive) — -(I)l / -(I)n
```
yap-ıl-mak          להיעשות (to be done)
sev-il-mek           להיות אהוב (to be loved)
```

### ו.2 גורם (Causative) — -DIr / -t / -Ir / -Er
```
yap-tır-mak          לגרום לעשות
oku-t-mak            לגרום לקרוא = ללמד
```

### ו.3 הדדי (Reciprocal) — -(I)ş
```
gör-üş-mek           להיפגש (לראות זה את זה)
```

### ו.4 רפלקסיבי (Reflexive) — -(I)n
```
giy-in-mek           להתלבש (ללבוש את עצמו)
```

### ו.5 Evidentiality — ראייתיות
```
-DI  = ראייתי (ראיתי, חוויתי)
-mIş = לא-ראייתי (שמעתי, הסקתי, גיליתי)

Yağmur yağdı.        ירד גשם (ראיתי).
Yağmur yağmış.       ירד גשם (כך אמרו לי / ראיתי שרטוב).
```

# מסלול נטיות שם (Cases Track) — שש הנטיות הטורקיות

## הרעיון המרכזי לדוברי עברית

בעברית, יחסים תחביריים מסומנים במילות יחס: **ב**בית, **ל**בית, **מ**בית, **של** בית, **את** הבית.
בטורקית, אותם יחסים מסומנים ב**סיומות שמודבקות לשם העצם**: ev**de**, ev**e**, ev**den**, ev**in**, ev**i**.

**חשבו על זה כך: מילות היחס העבריות "הודבקו" לסוף המילה.**

---

## שש הנטיות

### 1. Nominative (נומינטיב) — ∅
**תפקיד**: נושא המשפט; שם עצם לא-מיודע כמושא ישיר.
**סיומת**: אין (צורת בסיס).
**מקבילה עברית**: שם עצם בלי מילת יחס.

```
Ali geldi.              עלי בא.
Bir kitap aldım.        קניתי ספר (לא מסוים).
```

### 2. Accusative (אקוזטיב) — -(y)I
**תפקיד**: מושא ישיר **מיודע** (definite direct object).
**סיומת**: -ı / -i / -u / -ü (הרמוניית תנועות I-type); -yı / -yi / -yu / -yü אחרי תנועה.
**מקבילה עברית**: **את** + שם עצם מיודע.

```
Kitabı aldım.           לקחתי את הספר.
  kitab-ı = book-ACC

Ali'yi gördüm.          ראיתי את עלי.
  Ali-yi = Ali-ACC
```

**חשוב**: אם המושא לא מיודע — אין סיומת!
```
Bir kitap aldım.        קניתי ספר.     (indefinite → no ACC)
Kitabı aldım.           לקחתי את הספר.  (definite → ACC)
```

**השוואה**: בעברית, "את" מופיע רק עם מושא מיודע: "אכלתי תפוח" vs. "אכלתי **את** התפוח". בדיוק אותו כלל בטורקית!

### 3. Dative (דטיב) — -(y)E
**תפקיד**: כיוון, מושא עקיף, מטרה.
**סיומת**: -a / -e (הרמוניית תנועות E-type); -ya / -ye אחרי תנועה.
**מקבילה עברית**: **ל-** (לבית, לאיש).

```
Eve gidiyorum.          אני הולך לבית.
  ev-e = house-DAT

Ali'ye verdim.          נתתי לעלי.
  Ali-ye = Ali-DAT

Okula başladım.         התחלתי (ב)בית ספר.
  okul-a = school-DAT
```

### 4. Locative (לוקטיב) — -DE
**תפקיד**: מיקום, זמן.
**סיומת**: -da / -de (E-type); -ta / -te אחרי עיצורים חסרי-קול (ç, f, h, k, p, s, ş, t).
**מקבילה עברית**: **ב-** (בבית, בעיר).

```
Evde oturuyorum.        אני יושב בבית.
  ev-de = house-LOC

Okulda çalışıyorum.    אני לומד בבית הספר.
  okul-da = school-LOC

İstanbul'da yaşıyorum. אני גר באיסטנבול.
  İstanbul-da = Istanbul-LOC
```

### 5. Ablative (אבלטיב) — -DEn
**תפקיד**: מקור, סיבה, השוואה.
**סיומת**: -dan / -den (E-type); -tan / -ten אחרי עיצורים חסרי-קול.
**מקבילה עברית**: **מ-** (מבית, מהעיר).

```
Evden çıktım.           יצאתי מהבית.
  ev-den = house-ABL

İstanbul'dan geldim.    באתי מאיסטנבול.
  İstanbul-dan = Istanbul-ABL

Senden büyüğüm.        אני גדול ממך.
  sen-den = you-ABL
```

### 6. Genitive (גניטיב) — -(n)In
**תפקיד**: שייכות, בעלות.
**סיומת**: -ın / -in / -un / -ün (I-type); -nın / -nin / -nun / -nün אחרי תנועה.
**מקבילה עברית**: **של** (של הבית, של עלי); סמיכות.

```
Evin kapısı.            הדלת של הבית.
  ev-in kapı-sı = house-GEN door-3SG.POSS

Ali'nin kitabı.         הספר של עלי.
  Ali-nin kitab-ı = Ali-GEN book-3SG.POSS
```

**חשוב**: Genitive תמיד מלווה סיומת שייכות על השם השני (possessive suffix) — כמו סמיכות בעברית!
- Genitive + Possessive = סמיכות טורקית
- evin kapısı = שער הבית (מילולית: של-הבית שער-שלו)

## סדר הצגה בקורס

### A1.1 (שיעורים 1–12)
- **שיעור 1**: NOM (ברירת מחדל)
- **שיעור 3**: LOC (-DE) — "איפה אתה?" → Neredesin? Evdeyim.
- **שיעור 6**: ACC (-(y)I) — מושא ישיר מיודע
- **שיעור 8**: DAT (-(y)E) + ABL (-DEn) — כיוון ומקור
- **שיעור 9**: GEN (-(n)In) — שייכות

### A1.2 (שיעורים 1–12)
- שילוב כל שש הנטיות
- נטיות + רבים: evlerde, evlerden, evlerin
- נטיות + שייכות: evimde, evimden, evimin
- שרשורים: evlerimizden (מהבתים שלנו)

### A2 ומעלה
- שימושים מתקדמים: ABL להשוואה, DAT עם פעלים ספציפיים
- ביטויים קבועים עם נטיות
- מיחזור מתמיד דרך C1

## שגיאות נפוצות צפויות לדוברי עברית

### 1. שכחת ACC עם מושא מיודע
❌ *Kitap aldım.* (כשהכוונה לספר מסוים)
✅ Kitab**ı** aldım.

**הסבר**: בעברית, "את" הוא מילה נפרדת ולפעמים מושמט בדיבור. בטורקית, הסיומת -I חובה.

### 2. שימוש ב-ACC עם מושא לא-מיודע
❌ *Bir kitab**ı** aldım.*
✅ Bir kitap aldım.

**הסבר**: כמו בעברית — "קניתי ספר" (בלי "את"), כך בטורקית: indefinite = no ACC.

### 3. בלבול LOC ו-DAT
❌ *Eve oturuyorum.* (DAT במקום LOC)
✅ Ev**de** oturuyorum.

**הסבר**: LOC (-DE) = מיקום סטטי (ב-); DAT (-(y)E) = כיוון/תנועה (ל-).
בעברית: "אני **ב**בית" (LOC) vs. "אני הולך **ל**בית" (DAT).

### 4. שכחת שייכות עם GEN
❌ *Ali'nin kitap*
✅ Ali'nin kitab**ı**

**הסבר**: ב-Genitive, השם השני חייב סיומת שייכות. כמו בסמיכות עברית: "ספר**ו** של עלי".
